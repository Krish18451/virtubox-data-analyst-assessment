# VirtuBox Data Analyst Assessment

## Project Overview

This repository contains my submission for the VirtuBox Infotech Pvt. Ltd. Data Analyst Assessment.

The analysis focuses on understanding sales performance, revenue trends, customer purchasing behavior, product demand, geographical performance, and potential business opportunities using an online retail transaction dataset.

## Dataset

- Dataset: Online Retail II Dataset
- Source: UCI Machine Learning Repository / Kaggle
- Period: December 2009 to December 2011
- Records: 1,067,371 transactions
- Columns: 8

## Analysis Workflow

1. Dataset collection
2. Data cleaning and preprocessing using Python and Pandas
3. Handling missing values and duplicate records
4. Identifying cancellations, returns, and unusual values
5. Revenue calculation using Quantity × Unit Price
6. Exploratory Data Analysis (EDA)
7. Business insights and recommendations
8. Interactive dashboard using Google Looker Studio
9. Final presentation
